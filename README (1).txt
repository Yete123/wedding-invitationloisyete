Replace the file "song.mp3" with your own background music file.

Recommended:
- File format: .mp3 (most universally supported on iOS + Android browsers)
- Duration: 2–4 minutes (it loops automatically)
- File size: under 2MB for fast loading
- Volume: pre-normalize the song to a moderate level — the site sets
  player volume to 50%, so loud tracks will be loud.

The filename MUST stay "song.mp3" because index.html references it by that
name. If you want a different filename, also update the <source> tag in
index.html.
