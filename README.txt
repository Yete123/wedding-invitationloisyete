Place your wedding photos here. Replace the placeholder files with the
same filenames so the website picks them up automatically — no code changes
needed.

Required files (already created as placeholders):

  cover.jpg   — Full-screen cover background photo
                Recommended: portrait orientation, at least 1080×1620 px
                Tip: a romantic pre-wedding photo of the couple works best.

  groom.jpg   — Groom profile photo (square, ~800×800 px or larger)

  bride.jpg   — Bride profile photo (square, ~800×800 px or larger)

Just upload your own photos with these exact filenames to this folder and
the website will update automatically after you commit + push to GitHub.

Tips for best results:
- Compress photos before uploading: keep each under ~300 KB.
  Use https://tinypng.com or https://squoosh.app
- Use the same aspect ratio as the placeholders for the best layout.
- The cover image is shown full-bleed; portrait orientation works best on mobile.
- Profile photos are displayed as circles, so center the face.
